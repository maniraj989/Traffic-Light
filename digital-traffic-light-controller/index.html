Project Name: Digital Traffic Light Controller

The Digital Traffic Light Controller is a web-based simulation designed to demonstrate the working principle of an automated traffic signal system. It controls traffic flow at a four-way intersection by managing signal timing and switching between red, yellow and green lights. The project demonstrates basic traffic management logic through an interactive web interface.

Project Objectives

  • Demonstrate automated traffic signal management at a 4-way intersection.
  • Implement a reliable 6-phase Finite State Machine (FSM) ensuring safe signal clearance.
  • Eliminate conflicting traffic movements by strictly preventing simultaneous green signals.
  • Provide manual operator override with built-in safety interlocks and yellow clearances.
  • Simulate real-world density adaptations (Low, Medium, High traffic green intervals).

Technologies Used

  • HTML5: Semantic document structure, accessible ARIA attributes, SVG vector rendering.
  • CSS3: Custom Properties, Grid/Flexbox layouts, realistic signal housings, crosswalk styling.
  • Vanilla JavaScript (ES6+): Single-interval deterministic timer, state machine transitions, event dispatching.
  • Zero Dependencies: 100% native client-side execution; fully compatible with modern browsers, GitHub Pages, and Vercel.

Working Principle: 6-Phase Signal State Sequence

The controller operates on an algorithmic Finite State Machine (FSM). Opposite arterial directions (North & South) share identical green/yellow phases, while orthogonal directions (East & West) are held at solid Red. Before granting green to the opposing arterial, a 3-second Yellow caution and a mandatory 1-second All-Red clearance interval guarantee the intersection is physically vacated.

Phase North & South Signals East & West Signals Standard Timing Operational Purpose
Phase 1 GREEN (Active) RED (Hold) 15s (10s Low, 20s High) Allows North-South vehicular and pedestrian right-of-way.
Phase 2 YELLOW (Caution) RED (Hold) 3s (Fixed) Warns oncoming North-South vehicles to prepare to stop.
Phase 3 RED (Hold) RED (Hold) 1s (Safety Clearance) All-Red intersection safety buffer; clears remaining vehicles.
Phase 4 RED (Hold) GREEN (Active) 15s (10s Low, 20s High) Allows East-West vehicular and pedestrian right-of-way.
Phase 5 RED (Hold) YELLOW (Caution) 3s (Fixed) Warns oncoming East-West vehicles to prepare to stop.
Phase 6 RED (Hold) RED (Hold) 1s (Safety Clearance) All-Red intersection safety buffer before restarting cycle.
